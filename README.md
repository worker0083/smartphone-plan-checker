# スマホ・ネット・でんき 料金診断（関西エリア向け）

スマホ代・自宅のインターネット代・電気代をまとめて入力すると、
各社（ドコモ / au / UQ mobile / ソフトバンク / ワイモバイル / LINEMO / 楽天モバイル / mineo / IIJmio）ごとに
「プラン × ネット回線 × でんき」の全組み合わせからいちばん安いものを計算し、家計全体の月額で比べる Web ツールです。
特定の会社をひいきせず、セット割・家族割・カード払い割を各社のルールどおりに反映します。

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。
公開URL: https://worker0083.github.io/smartphone-plan-checker/

## 料金データの更新

料金はすべて `plans.js` にまとめています。
✅ は2026年11月に公式サイトで確認した値、⚠ は目安です。定期的に公式サイトを確認して更新してください。

## バージョンの上げ方（更新を公開するとき）

画面右上にバージョン（例：v1.6.0）が表示されます。古いページを開いている人には「最新版に更新」ボタンが出ます。
更新を公開するときは、次の3か所を同じ番号にそろえてください。

1. `version.json` の `version` と `date`
2. `index.html` の `APP_VERSION` と `APP_DATE`
3. `index.html` の `plans.js?v=…`
