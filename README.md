# スマホ・ネット・でんき 料金診断（関西エリア向け）

スマホ代・自宅のインターネット代・電気代をまとめて入力すると、
au / UQ mobile ＋ セット割対象の光回線（eo光など）＋ auでんき に切り替えた場合の
月額・年額の差を試算する Web ツールです。

- 📱 スマホ：au・UQ mobile の料金（セット割・家族割・au PAY カード割を反映）と他社の目安を比較
- 🌐 自宅ネット：eo光・auひかり・ドコモ光・ソフトバンク光・NURO光 を比較（セット割対象かを表示）
- 💡 でんき：関西電力（従量電灯A / なっトクパック）から auでんき に切り替えた場合のシミュレーション

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。
公開URL: https://worker0083.github.io/smartphone-plan-checker/
