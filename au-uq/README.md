# au・UQ mobile 乗り換え診断

ドコモ・ソフトバンク・ワイモバイル・楽天モバイル・ahamo/LINEMO・格安SIM から
au / UQ mobile に乗り換えたときの月額と節約額を計算する Web ツールです。

- 1人ずつのデータ量・通話の使い方から、各社でいちばん安いプランを自動で選びます
- 「全員au」「全員UQ mobile」「auとUQの組み合わせ」を比べて、いちばん安い形をおすすめします
- 家族割（すでにau/UQを使っている家族も回線数に入れられます）・自宅セット割（eo光/auひかり・auでんき）・au PAYカード払い割を反映します
- まだ使っていない割引でさらに安くなる場合はヒントを表示します
- 家族割（au 家族割プラス・UQ 家族セット割）の回線数・割引額・付かない理由を、結果ごとにまとめて表示します
- 1人ずつ「おまかせ／au に固定／UQ mobile に固定」をボタンで選べます
- 乗り換えない家族のスマホ代を入れると、家族全体の合計で比べます（すでに au / UQ の家族の家族割が増える分も目安で反映）
- 自宅のネットを auひかりプラス（関西・戸建て/マンション）にした場合を「ネットのみ」「ネット＋電話」で比較します（ネットのみはセット割の対象外）
- 「ネットを変える？」のボタン（今のまま／auひかりプラス ネットのみ／ネット＋電話）で選んだ内容が、スマホ料金のセット割と家計の合計に反映されます
- 電気代を入れると、auでんきに変えた場合の差額（ポイント還元・UQのでんきセット割）を計算します

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## 料金データの更新

料金はすべて `plans.js` にまとめています。✅ は2026年11月に公式サイトで確認した値、⚠ は目安です。
更新したら `index.html` の `APP_VERSION` と `plans.js?v=…` の番号を上げてください。
