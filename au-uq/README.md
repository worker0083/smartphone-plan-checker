# 料金診断（au・UQ mobile）

ドコモ・ソフトバンク・ワイモバイル・楽天モバイル・ahamo/LINEMO・格安SIM から
au / UQ mobile に乗り換えたときの月額と節約額を計算する Web ツールです。

- 1人ずつ今のキャリア（ドコモ・ソフトバンク・ワイモバイル・楽天・ahamo/LINEMO・格安SIM・au・UQ mobile）と使い方を入れます（「＋ 人を追加」「削除」で人数を変更）
- au・UQ mobile の人は「今のプラン」（新規受付終了の過去プランを含む）を選ぶと、今の月額を計算して見直し後と比べます。今のプランのままが安い人はそのまま残します
- 結果に「1人ずつの比較」（今 → おすすめを並べて、ギガ・月額と「月◯円安い」「ギガ◯GB増える」を表示）と、乗り換え・プラン変更・番号移行の手続きの流れを表示します
- 1人ずつのデータ量・通話の使い方から、各社でいちばん安いプランを自動で選びます
- 「全員au」「全員UQ mobile」「auとUQの組み合わせ」を比べて、いちばん安い形をおすすめします
- 家族割（すでにau/UQを使っている家族も回線数に入れられます）・自宅セット割（eo光/auひかり・auでんき）・au PAYカード払い割を反映します
- まだ使っていない割引でさらに安くなる場合はヒントを表示します
- 家族割（au 家族割プラス・UQ 家族セット割）の回線数・割引額・付かない理由を、結果ごとにまとめて表示します
- 1人ずつ「おまかせ／au に固定／UQ mobile に固定」をボタンで選べます
- 今のネット会社（eo光・auひかり・ビッグローブ光・So-net光・@nifty光・J:COM・auホームルーター・ドコモ光・ソフトバンク光・NURO光・楽天ひかり・フレッツ光など）を選ぶと、セット割の対象かどうかを判定し、月額の目安を入れます
- 乗り換えない家族のスマホ代を入れると、家族全体の合計で比べます（すでに au / UQ の家族の家族割が増える分も目安で反映）
- 自宅のネットを auひかりプラス（関西・戸建て/マンション・1ギガ/10ギガ）にした場合を「ネットのみ」「ネット＋電話」で比較します（ネットのみはセット割の対象外）
- 「ネットを変える？」のボタン（今のまま／auひかりプラス ネットのみ／ネット＋電話）で選んだ内容が、スマホ料金のセット割と家計の合計に反映されます
- 電気代を入れると、auでんきに変えた場合の差額（ポイント還元・UQのでんきセット割）を計算します
- 電気代がわからないときは、家族の人数・住まい・時期・日中の過ごし方から電気代の目安を計算して入れられます
- 「クリア」ボタンで入力をすべて最初の状態に戻せます（次のお客さまの診断用）

## 使い方

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

## 料金データの更新

料金はすべて `plans.js` にまとめています。✅ は2026年11月に公式サイトで確認した値、⚠ は目安です。
## バージョンの上げ方（更新を公開するとき）

画面上部にバージョン（例：v1.6.0）と「更新を確認」が表示されます。
古いページを開いている人には「最新版に更新」ボタンが出て、押すと入力内容を残したまま最新版に切り替わります。
更新を公開するときは、次の3か所を同じ番号にそろえてください。

1. `version.json` の `version`・`date`・`notes`（notes は更新ボタンの横に表示されます）
2. `index.html` の `APP_VERSION` と `APP_DATE`
3. `index.html` の `plans.js?v=…`
